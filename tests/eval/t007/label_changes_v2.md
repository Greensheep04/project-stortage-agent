## 1. 更正方法（归组规则＋逐篇判定）

- 对两份已保存报告（dev 四组、test phrase）中**全部返回候选**（各查询候选排名前 50）逐项判定；未判定项一律补齐，不默认计 0。
- 子主题归组：案例按标题主题（如货位记录滞后短拣、补货未登记短拣、多货位短拣、统计口径误报、明细串记、草稿跨班次/超时、流水多录冲销、冲销关联错误、破损索赔缺记录、签收缺失/延迟补录、交接状态不一致/缺待办、保存期限、归档缺件等；分批按“登记延迟”细分）；SOP 按政策（policy）。
- 判定规则：
  - 与本题已判定等级 2 文档同子主题 → 等级 2（直接满足，补标）；
  - 与本题已判定等级 1 文档同子主题 → 等级 1（有帮助但不能独立满足）；
  - 其余 → 等级 0，理由写明子主题与“与本题场景不同”的结论，不以“关键词未命中”作为唯一依据。
- 时间／范围排除由查询输入（as_of、warehouse/sku）与语料结构化字段解释；返回候选均已通过过滤，不需要额外排除解释。
