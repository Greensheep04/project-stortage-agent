## 2. 标注口径

- 等级 2＝直接满足该查询的信息需要；1＝有帮助但不能独立满足；0＝无关，或虽相似却不适用。
- 时间规则（与 T-006c 修正后的语料口径一致）：事件 `occurred_at`、`recorded_at` ≤ T；案例 `closed_at`、`recorded_at` ≤ T；SOP `recorded_at` ≤ T 且 `effective_from` ≤ T < `effective_to`（过期或未生效版本标 0，不标 1）。
- 范围规则：仓库／SKU 精确匹配或 null 通用；案例范围为 null 不视为满足一个具体范围。
- 语料用语重复时，同主题不同父文档都按原文判定；等级 2 文档单题不超过 10 篇（实际 dev ≤7、test ≤8），每道正向题至少 1 篇等级 2。
- 标注流程：先用关键词辅助扫描按主题归组（不使用系统 Top-k 或生成模型输出当真值），再逐篇阅读原文判定；dev 基线运行后，对三组返回并集中仍未标注的文档逐篇判定并显式补标（主题不同记 0 并写明理由），避免“未标注直接算不相关”。

## 3. 分组与防泄漏

- dev/test 按场景意图分割；同一问题的改写与同案例近重复提问不跨组；两集查询文本无重复。
- 测试题不复制标题、doc_id 或模板句；32 道测试正向题全部使用改写表达（≥16 的要求已满足）。
- T-006 已曝光的 14 功能场景未作为本评测盲测；CASE-0001/0011 按具体问题单独判定，不要求无条件命中。

## 4. 负向题

- dev 4 题（case 2＋sop 2）、test 8 题（case 4＋sop 4），每题写明不适用理由；负向题不设等级 2。
- 主题选择前做了词汇冲突扫描：冷链、温控、退货、换货、移库、供应商来料、消防、危险品、赔付审批等在语料中无对应正文或制度。

## 5. 计分口径（与 E2/D14 一致）

- Recall@10＝Top-10 命中的不同等级 2 父文档数／全部等级 2 父文档数（掉出 Top-10 的等级 2 仍进分母）。
- MRR@5＝前 5 名内首个等级 2 的排名倒数，无命中记 0。
- nDCG@5：gain＝2^等级−1，折损 log2(rank+1)，理想排名来自完整标签（含未进 Top-10 的等级 2）。
- 同一父文档只计一次；技术失败的正向题记 0 并保留在分母；负向题单列数量、返回内容与错误，不计入正向指标；进程存在失败时非零退出并保留部分结果报告。
- 候选 Recall@50 位置留空（T-007b 的 rerank 前候选口径）。
